# xP Model (Part 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Predict every FPL player's expected points (xP) for the next 1–6 gameweeks from per-event models, prove it with a leakage-free walk-forward backtest on 2025/26 against model B and a last-5 baseline, and print a ranked table.

**Architecture:** One tidy match table (vaastav 2022/23–2025/26 + our 2026/27 pull, finished fixtures only) → a `FeatureBuilder` that only sees the history it is given and computes "as-of" rolling features with priors for newcomers/promoted teams → one LightGBM model per scoring part → season-aware FPL rules turn parts into xP. The backtest hands the builder only pre-cutoff history at every step.

**Tech Stack:** Python 3.13, pandas, numpy, LightGBM, pytest.

**Spec:** `docs/superpowers/specs/2026-10-10-xp-model-design.md` (read it first; this plan implements it).

## Global Constraints

- Training seasons: `2022-23`, `2023-24`, `2024-25`, `2025-26` (vaastav) + `2026-27` (our pull). Nothing earlier.
- Only **finished** fixtures enter the match table.
- Every join between fixtures/teams/players keys on `season` as well as `fixture_id` (fixture ids restart each season).
- Features for a row use only matches with `kickoff_time < asof`; `asof` = first kickoff of the row's gameweek (or of the prediction gameweek for multi-week rows).
- Blend: `(n·value + K·prior)/(n + K)`, n = player's/team's **total** past matches of the relevant kind (never capped at the window). K = 5 players, 6 teams.
- Scoring rules are season-aware: GK goal 6 before 2026/27, 10 from 2026/27; DefCon points 0 before 2025/26, else 2 (DEF ≥10 CBIT; MID/FWD ≥12 CBIRT; GK none).
- DefCon model trains only on rows with DefCon data (2025/26+). Bonus model weights 2026/27 rows ×3.
- Clean-sheet points use P(team CS) × P(60+).
- Files follow the existing pattern: `api.py` is the only internet code, `storage.py` the only disk code; pure logic is disk-free and tested offline.
- Tests never use the internet. Run tests with `python -m pytest`.
- New dependency: `lightgbm` only.

## Review Focus

1. **A double gameweek** (two fixtures in one GW): both fixtures must get identical player features (the second must not see the first), and xP must be summed per player per GW in the backtest and the ranked table. → Task 5 `test_both_fixtures_of_a_double_gameweek_get_the_same_player_features`, Task 7 `test_double_gameweek_fixtures_are_added_together`, Task 9 test.
2. **A team with a blank next gameweek**: its players must still appear in a multi-week table with 0 for the blank week and "-" as next fixture. → Task 9 `test_ranked_table_sums_double_gameweeks_and_handles_blanks`.
3. **A just-signed player with no rows in history**: prediction must be finite, built from priors. → Task 6 `test_a_brand_new_player_gets_a_finite_prediction`.
4. **Fixture ids repeating across seasons**: team pairing must not cross seasons. → Task 4 `test_team_matches_pair_teams_within_the_same_season` (synthetic data restarts fixture ids each season).
5. **A player flagged 0% / 50% by FPL**: xP drops only for the next GW, later weeks untouched. → Task 6 `test_apply_availability_caps_next_gameweek_only`.

```python
"""FPL's scoring rules, season by season, in one place.

Used two ways: rebuilding official points from match stats (which checks the
rules are right), and turning the model's part predictions into expected
points. Nothing here touches the internet or the disk.
"""
from dataclasses import dataclass

import numpy as np
import pandas as pd

POSITIONS = ("GK", "DEF", "MID", "FWD")
ASSIST_POINTS = 3
SAVES_PER_POINT = 3
GOALS_CONCEDED_PER_MINUS_POINT = 2
# Defensive actions needed for DefCon points. Goalkeepers can't earn them.
DEFCON_THRESHOLD = {"DEF": 10, "MID": 12, "FWD": 12}
RULES_ERA_CODE = {"pre_2025": 0, "2025_26": 1, "2026_27": 2}
POINT_PARTS = ["pts_minutes", "pts_goals", "pts_assists", "pts_clean_sheet",
               "pts_goals_conceded", "pts_saves", "pts_cards", "pts_defcon", "pts_bonus"]


@dataclass(frozen=True)
class Rules:
    goal: dict          # points per goal, by position
    clean_sheet: dict   # points per clean sheet, by position
    defcon_points: int  # points for reaching the DefCon threshold


def rules_for(season: str) -> Rules:
    year = int(season[:4])
    return Rules(
        goal={"GK": 10 if year >= 2026 else 6, "DEF": 6, "MID": 5, "FWD": 4},
        clean_sheet={"GK": 4, "DEF": 4, "MID": 1, "FWD": 0},
        defcon_points=2 if year >= 2025 else 0,
    )


def rules_era(season: str) -> str:
    """Which bonus/DefCon rule set a season uses. Later seasons reuse the newest."""
    year = int(season[:4])
    if year >= 2026:
        return "2026_27"
    return "2025_26" if year == 2025 else "pre_2025"


def defcon_actions(matches: pd.DataFrame) -> pd.Series:
    """Defensive actions that count for each row's position.

    DEF: clearances/blocks/interceptions + tackles (CBIT). MID/FWD: CBIT plus
    recoveries (CBIRT). NaN for goalkeepers and seasons without DefCon data.
    """
    cbit = matches["clearances_blocks_interceptions"] + matches["tackles"]
    cbirt = cbit + matches["recoveries"]
    position = matches["position"]
    return cbit.where(position == "DEF", cbirt.where(position.isin(["MID", "FWD"])))


def defcon_hit(matches: pd.DataFrame) -> pd.Series:
    """1.0 if the row reached its position's DefCon threshold, 0.0 if not, NaN if unknown."""
    actions = defcon_actions(matches)
    threshold = matches["position"].map(DEFCON_THRESHOLD)
    return (actions >= threshold).astype(float).where(actions.notna() & threshold.notna())


def _per_row(frame: pd.DataFrame, pick) -> pd.Series:
    """A by-position rule value for each row, using that row's season's rules."""
    return pd.Series([pick(rules_for(s))[p] for s, p in zip(frame["season"], frame["position"])],
                     index=frame.index, dtype=float)


def actual_points(matches: pd.DataFrame) -> pd.Series:
    """Rebuild official FPL points from match stats, using each row's season rules."""
    position = matches["position"]
    minutes = matches["minutes"]
    defcon_points = matches["season"].map(lambda s: rules_for(s).defcon_points)
    points = (
        np.where(minutes >= 60, 2, np.where(minutes > 0, 1, 0))
        + matches["goals_scored"] * _per_row(matches, lambda r: r.goal)
        + matches["assists"] * ASSIST_POINTS
        + matches["clean_sheets"] * _per_row(matches, lambda r: r.clean_sheet)
        - np.where(position.isin(["GK", "DEF"]),
                   matches["goals_conceded"] // GOALS_CONCEDED_PER_MINUS_POINT, 0)
        + np.where(position == "GK", matches["saves"] // SAVES_PER_POINT, 0)
        + 5 * matches["penalties_saved"] - 2 * matches["penalties_missed"]
        - matches["yellow_cards"] - 3 * matches["red_cards"] - 2 * matches["own_goals"]
        + matches["bonus"]
        + defcon_points * defcon_hit(matches).fillna(0)
    )
    return pd.Series(points, index=matches.index).round().astype(int)


def expected_floor_div(lam, k: int, max_count: int = 40) -> np.ndarray:
    """E[floor(X / k)] for X ~ Poisson(lam): the expected value of '1 point per k events'."""
    lam = np.clip(np.asarray(lam, dtype=float), 1e-12, None)[..., None]
    n = np.arange(max_count + 1)
    log_factorial = np.concatenate([[0.0], np.cumsum(np.log(np.arange(1, max_count + 1)))])
    pmf = np.exp(n * np.log(lam) - lam - log_factorial)
    return (pmf * (n // k)).sum(axis=-1)


def expected_points(pred: pd.DataFrame) -> pd.DataFrame:
    """Turn per-fixture part predictions into expected FPL points.

    Needs one row per player per fixture with: season, position,
      p_plays, p_60     chance he plays at all / plays 60+ minutes
      xg, xa            expected goals / assists if he plays
      p_cs              chance his team keeps a clean sheet
      gc_lambda         his team's expected goals conceded
      saves_lambda      expected saves if he plays (goalkeepers)
      p_yellow, p_red   chance of a yellow / red card if he plays
      p_defcon          chance he reaches the DefCon threshold if he plays
      e_bonus           expected bonus points if he plays
    Returns a copy with one pts_* column per scoring part, then xp (their sum).
    """
    out = pred.drop(columns=POINT_PARTS + ["xp"], errors="ignore").copy()
    position = out["position"]
    plays, sixty = out["p_plays"], out["p_60"]
    defcon_points = out["season"].map(lambda s: rules_for(s).defcon_points)
    goals_conceded = expected_floor_div(out["gc_lambda"], GOALS_CONCEDED_PER_MINUS_POINT)
    saves = expected_floor_div(out["saves_lambda"], SAVES_PER_POINT)

    out["pts_minutes"] = (plays - sixty) * 1 + sixty * 2
    out["pts_goals"] = plays * out["xg"] * _per_row(out, lambda r: r.goal)
    out["pts_assists"] = plays * out["xa"] * ASSIST_POINTS
    # A clean sheet only counts if he plays 60+: P(clean sheet AND 60+ minutes).
    out["pts_clean_sheet"] = sixty * out["p_cs"] * _per_row(out, lambda r: r.clean_sheet)
    out["pts_goals_conceded"] = np.where(position.isin(["GK", "DEF"]), -sixty * goals_conceded, 0.0)
    out["pts_saves"] = np.where(position == "GK", plays * saves, 0.0)
    out["pts_cards"] = -plays * (out["p_yellow"] + 3 * out["p_red"])
    out["pts_defcon"] = np.where(position == "GK", 0.0, plays * out["p_defcon"] * defcon_points)
    out["pts_bonus"] = plays * out["e_bonus"]
    out["xp"] = out[POINT_PARTS].sum(axis=1)
    return out
```

```python
"""One tidy table of every player in every finished fixture, across seasons.

Past seasons come from the vaastav files saved by pull_history.py; the
current season from our own FPL API pull (pull_data.py). Only the load_*
functions read the disk, so the rest is easy to test.
"""
import pandas as pd

from fpl import storage
from fpl.scoring import rules_era
from fpl.seasons import CURRENT_SEASON, PAST_SEASONS

# element_type 5 was the 2024/25 Assistant Manager; those rows are dropped.
POSITION_BY_TYPE = {1: "GK", 2: "DEF", 3: "MID", 4: "FWD"}
# The same club is spelled differently in some seasons; map to one spelling.
TEAM_ALIASES = {"Ipswich Town": "Ipswich"}

STAT_COLUMNS = ["minutes", "starts", "goals_scored", "assists", "clean_sheets",
                "goals_conceded", "saves", "yellow_cards", "red_cards", "penalties_saved",
                "penalties_missed", "own_goals", "bonus", "bps", "expected_goals",
                "expected_assists", "expected_goals_conceded", "threat", "total_points"]
DEFCON_COLUMNS = ["clearances_blocks_interceptions", "tackles", "recoveries"]  # 2025/26 on
MATCH_COLUMNS = ["season", "gw", "kickoff_time", "fixture_id", "player_code", "player_name",
                 "position", "team", "opponent", "was_home", "price", "team_goals",
                 "opp_goals", *STAT_COLUMNS, *DEFCON_COLUMNS, "rules_era"]
# What is known about a fixture before it is played (inputs for predictions).
PLAYER_ROW_COLUMNS = ["season", "gw", "fixture_id", "kickoff_time", "player_code",
                      "player_name", "position", "price", "team", "opponent", "was_home"]
TEAM_ROW_COLUMNS = ["season", "gw", "fixture_id", "kickoff_time", "team", "opponent",
                    "was_home"]


def canonical_team(name: str) -> str:
    return TEAM_ALIASES.get(name, name)


def _team_names(teams: pd.DataFrame) -> dict:
    return {tid: canonical_team(name) for tid, name in zip(teams["id"], teams["name"])}


def fixture_list(season: str, fixtures: pd.DataFrame, teams: pd.DataFrame) -> pd.DataFrame:
    """Two rows per scheduled fixture (one per team), with kickoff and finished flag."""
    f = fixtures.dropna(subset=["event"])  # postponed fixtures without a new date have no GW
    names = _team_names(teams)
    base = pd.DataFrame({"season": season, "gw": f["event"].astype(int), "fixture_id": f["id"],
                         "kickoff_time": pd.to_datetime(f["kickoff_time"], utc=True),
                         "finished": f["finished"].astype(bool)})
    home = base.assign(team=f["team_h"].map(names), opponent=f["team_a"].map(names),
                       was_home=True, team_goals=f["team_h_score"], opp_goals=f["team_a_score"])
    away = base.assign(team=f["team_a"].map(names), opponent=f["team_h"].map(names),
                       was_home=False, team_goals=f["team_a_score"], opp_goals=f["team_h_score"])
    return (pd.concat([home, away], ignore_index=True)
            .sort_values(["kickoff_time", "fixture_id", "was_home"],
                         ascending=[True, True, False], ignore_index=True))


def build_season(season: str, gws: pd.DataFrame, players: pd.DataFrame,
                 teams: pd.DataFrame, fixtures: pd.DataFrame) -> pd.DataFrame:
    """One row per player per finished fixture for one season (MATCH_COLUMNS).

    gws:      player-by-fixture stats (vaastav merged_gw.csv or our player_history.csv)
    players:  id, code (permanent across seasons), element_type, web_name
    teams:    id, name
    fixtures: FPL fixtures (id, event, kickoff_time, team_h, team_a, scores, finished)
    """
    fx = fixture_list(season, fixtures, teams)
    fx = fx[fx["finished"]].drop(columns="finished")
    keep = ["element", "fixture", "was_home", "value", *STAT_COLUMNS,
            *[c for c in DEFCON_COLUMNS if c in gws.columns]]
    rows = gws[keep].drop_duplicates(subset=["element", "fixture"])
    # The team side of each row comes from the fixture plus home/away.
    rows = rows.merge(fx, left_on=["fixture", "was_home"], right_on=["fixture_id", "was_home"])
    people = players[["id", "code", "element_type", "web_name"]].rename(
        columns={"id": "element", "code": "player_code", "web_name": "player_name"})
    rows = rows.merge(people, on="element")
    rows["position"] = rows["element_type"].map(POSITION_BY_TYPE)
    rows = rows[rows["position"].notna()].copy()
    rows["price"] = rows["value"] / 10
    for col in DEFCON_COLUMNS:
        if col not in rows:
            rows[col] = float("nan")
    rows["rules_era"] = rules_era(season)
    return rows[MATCH_COLUMNS].sort_values(["kickoff_time", "fixture_id", "player_code"],
                                           ignore_index=True)


def _season_files(season: str):
    """(gws, players, teams, fixtures) for one season, from disk."""
    if season == CURRENT_SEASON:
        return tuple(storage.load_table(n) for n in
                     ("player_history", "players", "teams", "fixtures"))
    return tuple(storage.load_vaastav(season, p) for p in storage.VAASTAV_FILES)


def load_all_matches() -> pd.DataFrame:
    """Every finished player-fixture from 2022/23 to now. Run pull_history.py and pull_data.py first."""
    seasons = [build_season(s, *_season_files(s)) for s in PAST_SEASONS + [CURRENT_SEASON]]
    return pd.concat(seasons, ignore_index=True)


def load_all_fixtures() -> pd.DataFrame:
    """Every scheduled fixture (finished or not), two rows each, all seasons."""
    lists = []
    for s in PAST_SEASONS + [CURRENT_SEASON]:
        _, _, teams, fixtures = _season_files(s)
        lists.append(fixture_list(s, fixtures, teams))
    return pd.concat(lists, ignore_index=True)


def gw_cutoffs(fixtures_all: pd.DataFrame) -> pd.DataFrame:
    """First kickoff of each gameweek: predictions for it may only use earlier matches."""
    return (fixtures_all.groupby(["season", "gw"], as_index=False)["kickoff_time"].min()
            .rename(columns={"kickoff_time": "cutoff"}))


def with_asof(rows: pd.DataFrame, cutoffs: pd.DataFrame) -> pd.DataFrame:
    """Add `asof` = the cutoff of each row's own gameweek (keeps row order)."""
    return rows.merge(cutoffs.rename(columns={"cutoff": "asof"}), on=["season", "gw"], how="left")


def finished_gws(fixtures_all: pd.DataFrame, season: str) -> list[int]:
    """Gameweeks of a season whose fixtures have all finished."""
    done = fixtures_all[fixtures_all["season"] == season].groupby("gw")["finished"].all()
    return sorted(int(gw) for gw in done.index[done])


def upcoming_player_rows(fixtures_all, players, teams, season, gws) -> pd.DataFrame:
    """One row per current player per fixture of his team in `gws` (PLAYER_ROW_COLUMNS).

    players is our processed players.csv; status 'u' means he has left the club.
    """
    squad = players[players["status"] != "u"]
    squad = pd.DataFrame({"player_code": squad["code"], "player_name": squad["web_name"],
                          "position": squad["element_type"].map(POSITION_BY_TYPE),
                          "price": squad["now_cost"] / 10,
                          "team": squad["team"].map(_team_names(teams))})
    squad = squad[squad["position"].notna()]
    fx = upcoming_team_rows(fixtures_all, season, gws)
    rows = fx.merge(squad, on="team")
    return rows[PLAYER_ROW_COLUMNS].sort_values(["kickoff_time", "fixture_id", "player_code"],
                                                ignore_index=True)


def upcoming_team_rows(fixtures_all, season, gws) -> pd.DataFrame:
    fx = fixtures_all[(fixtures_all["season"] == season) & fixtures_all["gw"].isin(gws)]
    return fx[TEAM_ROW_COLUMNS].reset_index(drop=True)
```

```python
"""A small made-up league shaped exactly like the real match table.

Alpha, Bravo and Charlie play both seasons; Delta is relegated after 2024-25
and Echo (all new players) is promoted for 2025-26. Player 999 ("Mover")
plays for Alpha in 2024-25 and Bravo in 2025-26. Fixture ids restart each
season, as in real FPL data.
"""
import numpy as np
import pandas as pd
import pytest

from fpl import scoring
from fpl.matches import DEFCON_COLUMNS, MATCH_COLUMNS

TEAMS = {"2024-25": ["Alpha", "Bravo", "Charlie", "Delta"],
         "2025-26": ["Alpha", "Bravo", "Charlie", "Echo"]}
POSITIONS = ["GK", "DEF", "MID", "FWD"]
TEAM_CODE = {"Alpha": 100, "Bravo": 200, "Charlie": 300, "Delta": 400, "Echo": 500}
MOVER = 999
# Each gameweek's pairings (indexes into the season's team list), home team first.
PAIRINGS = [[(0, 1), (2, 3)], [(2, 0), (3, 1)], [(0, 3), (1, 2)]]


def squad(team, season):
    """(player_code, position, price) for each player in a team that season."""
    players = [(TEAM_CODE[team] + i, pos, 4.5 + 1.5 * i) for i, pos in enumerate(POSITIONS)]
    if (team, season) in {("Alpha", "2024-25"), ("Bravo", "2025-26")}:
        players.append((MOVER, "MID", 8.0))
    return players


def make_matches(gws=6, seed=0):
    rng = np.random.default_rng(seed)
    rows = []
    for season, teams in TEAMS.items():
        start = pd.Timestamp(f"{season[:4]}-08-16 14:00", tz="UTC")
        fixture_id = 0
        for gw in range(1, gws + 1):
            for slot, (h, a) in enumerate(PAIRINGS[(gw - 1) % len(PAIRINGS)]):
                fixture_id += 1
                kickoff = start + pd.Timedelta(days=7 * (gw - 1), hours=2 * slot)
                goals = {teams[h]: int(rng.poisson(1.4)), teams[a]: int(rng.poisson(1.1))}
                for team, opponent, home in [(teams[h], teams[a], True), (teams[a], teams[h], False)]:
                    for code, pos, price in squad(team, season):
                        minutes = int(rng.choice([0, 30, 90], p=[0.15, 0.15, 0.7]))
                        on = minutes > 0
                        attacker = on and pos != "GK"
                        rows.append({
                            "season": season, "gw": gw, "kickoff_time": kickoff,
                            "fixture_id": fixture_id, "player_code": code,
                            "player_name": f"P{code}", "position": pos, "team": team,
                            "opponent": opponent, "was_home": home, "price": price,
                            "team_goals": goals[team], "opp_goals": goals[opponent],
                            "minutes": minutes, "starts": int(minutes >= 60),
                            "goals_scored": int(rng.poisson(0.3)) if attacker else 0,
                            "assists": int(rng.poisson(0.2)) if attacker else 0,
                            "clean_sheets": int(minutes >= 60 and goals[opponent] == 0),
                            "goals_conceded": goals[opponent] if on else 0,
                            "saves": int(rng.poisson(3)) if on and pos == "GK" else 0,
                            "yellow_cards": int(on and rng.random() < 0.1), "red_cards": 0,
                            "penalties_saved": 0, "penalties_missed": 0, "own_goals": 0,
                            "bonus": int(rng.choice([0, 0, 0, 1, 2, 3])) if on else 0,
                            "bps": int(rng.integers(0, 40)) if on else 0,
                            "expected_goals": round(float(rng.gamma(1.0, 0.15)), 2) if attacker else 0.0,
                            "expected_assists": round(float(rng.gamma(1.0, 0.1)), 2) if attacker else 0.0,
                            "expected_goals_conceded": round(float(rng.gamma(2.0, 0.6)), 2) if on else 0.0,
                            "threat": round(float(rng.uniform(0, 50)), 1) if on else 0.0,
                            "clearances_blocks_interceptions": float(rng.integers(0, 9)) if on else 0.0,
                            "tackles": float(rng.integers(0, 5)) if on else 0.0,
                            "recoveries": float(rng.integers(0, 6)) if on else 0.0,
                            "total_points": 0, "rules_era": scoring.rules_era(season),
                        })
    m = pd.DataFrame(rows)
    m.loc[m["season"] < "2025-26", DEFCON_COLUMNS] = np.nan  # no DefCon data before 2025/26
    m["total_points"] = scoring.actual_points(m)
    return m[MATCH_COLUMNS]


def make_fixtures(matches):
    """The fixture list (as matches.load_all_fixtures returns it) for synthetic matches."""
    cols = ["season", "gw", "fixture_id", "kickoff_time", "team", "opponent", "was_home",
            "team_goals", "opp_goals"]
    return (matches[cols].drop_duplicates(["season", "fixture_id", "team"])
            .assign(finished=True).reset_index(drop=True))


@pytest.fixture
def history():
    return make_matches()
```

```python
"""Turn the match table into model inputs ("features") without peeking at the future.

Every feature for a row uses only matches that kicked off before the row's
`asof` time (its gameweek's first kickoff). FeatureBuilder only ever sees the
history it is given, so the backtest hands it data from before each cutoff.

Players and teams with little history are blended towards a sensible default
(a "prior"): feature = (n * own_value + K * prior) / (n + K), where n is the
player's (or team's) total number of past matches. The prior fades as n grows.
"""
import numpy as np
import pandas as pd

from fpl import scoring
from fpl.seasons import previous_season

TEAM_WINDOW = 6
TEAM_K = 6
TEAM_STATS = ["xg_for", "xg_against", "goals_for", "goals_against"]
TEAM_FEATURES = ([f"team_{s}" for s in TEAM_STATS] + [f"opp_{s}" for s in TEAM_STATS]
                 + ["was_home", "rules_era_code"])


def blend(value: pd.Series, n: pd.Series, prior: pd.Series, k: float) -> pd.Series:
    """Mix own value with a prior: (n * value + k * prior) / (n + k).

    No history (n = 0) gives the prior. History but nothing in this window
    (e.g. no minutes lately) gives NaN, which LightGBM treats as "missing".
    """
    mixed = (n * value + k * prior) / (n + k)
    return mixed.where(value.notna(), prior.where(n == 0))


def team_matches(history: pd.DataFrame) -> pd.DataFrame:
    """One row per team per fixture: goals and xG for and against."""
    keys = ["season", "gw", "fixture_id", "kickoff_time", "team", "opponent", "was_home"]
    t = history.groupby(keys, as_index=False).agg(
        goals_for=("team_goals", "first"), goals_against=("opp_goals", "first"),
        xg_for=("expected_goals", "sum"))
    against = t[["season", "fixture_id", "team", "xg_for"]].rename(
        columns={"team": "opponent", "xg_for": "xg_against"})
    t = t.merge(against, on=["season", "fixture_id", "opponent"], how="left")
    t["rules_era"] = t["season"].map(scoring.rules_era)
    return t.sort_values(["kickoff_time", "fixture_id", "team"], ignore_index=True)


def _check_asof(rows: pd.DataFrame) -> None:
    if "asof" not in rows or rows["asof"].isna().any():
        raise ValueError("every row needs an `asof` time (see matches.with_asof)")


def _team_state(tm: pd.DataFrame, spell_start: list) -> pd.DataFrame:
    """Rolling sums of each team's last TEAM_WINDOW matches within its current PL spell."""
    spell = pd.Series(spell_start, index=tm.index)
    keys = [tm["team"], spell]
    cols = {"team": tm["team"], "kickoff_time": tm["kickoff_time"], "spell_start": spell}
    for stat in TEAM_STATS:
        running = tm[stat].groupby(keys).cumsum()
        cols[f"{stat}__sum"] = running - running.groupby(keys).shift(TEAM_WINDOW).fillna(0)
    count = tm.groupby(keys).cumcount() + 1
    cols["count"] = count
    cols["window_count"] = count.clip(upper=TEAM_WINDOW)
    return pd.DataFrame(cols)


class FeatureBuilder:
    """Computes features from `history` only. Give it nothing you couldn't have known."""

    def __init__(self, history: pd.DataFrame):
        self.history = history.sort_values(["kickoff_time", "fixture_id", "player_code"],
                                           ignore_index=True)
        self.first_season = self.history["season"].min()

        self.team_matches = team_matches(self.history)
        tm = self.team_matches
        self._team_seasons = set(zip(tm["team"], tm["season"]))
        spell = [self._spell_start(t, s) for t, s in zip(tm["team"], tm["season"])]
        self.team_state = _team_state(tm, spell)
        league = tm[TEAM_STATS].mean()
        promoted_start = (np.array(spell, dtype=object) > self.first_season) & \
            (self.team_state["count"] <= TEAM_WINDOW).to_numpy()
        first_matches = tm[promoted_start]
        self.team_priors = {
            "league": league,
            "promoted": first_matches[TEAM_STATS].mean() if len(first_matches) >= TEAM_WINDOW else league,
        }

    def _spell_start(self, team: str, season: str) -> str:
        """First season of the team's current unbroken PL run (within our data)."""
        while (team, previous_season(season)) in self._team_seasons:
            season = previous_season(season)
        return season

    def _team_values(self, team: pd.Series, season: pd.Series, asof: pd.Series) -> dict:
        """Blended rolling team stats as of each row's asof, as numpy arrays in row order."""
        left = pd.DataFrame({"team": team.reset_index(drop=True),
                             "season": season.reset_index(drop=True),
                             "asof": asof.reset_index(drop=True)})
        left["_row"] = np.arange(len(left))
        spells = {key: self._spell_start(*key) for key in set(zip(left["team"], left["season"]))}
        left["spell_start"] = [spells[key] for key in zip(left["team"], left["season"])]
        state = self.team_state.add_prefix("s_").rename(columns={"s_team": "team"})
        m = pd.merge_asof(left.sort_values("asof", kind="stable"), state,
                          left_on="asof", right_on="s_kickoff_time", by="team",
                          allow_exact_matches=False, direction="backward")
        m = m.sort_values("_row").reset_index(drop=True)
        # A relegated-then-promoted team starts fresh: old-spell matches don't count.
        same_spell = m["s_spell_start"] == m["spell_start"]
        n = m["s_count"].where(same_spell, 0).fillna(0)
        promoted = m["spell_start"] > self.first_season
        out = {}
        for stat in TEAM_STATS:
            value = (m[f"s_{stat}__sum"] / m["s_window_count"]).where(same_spell)
            prior = pd.Series(np.where(promoted, self.team_priors["promoted"][stat],
                                       self.team_priors["league"][stat]), index=m.index)
            out[stat] = blend(value, n, prior, TEAM_K).to_numpy()
        return out

    def _add_team_features(self, rows: pd.DataFrame) -> pd.DataFrame:
        own = self._team_values(rows["team"], rows["season"], rows["asof"])
        opp = self._team_values(rows["opponent"], rows["season"], rows["asof"])
        for stat in TEAM_STATS:
            rows[f"team_{stat}"] = own[stat]
            rows[f"opp_{stat}"] = opp[stat]
        rows["was_home"] = rows["was_home"].astype(int)
        rows["rules_era_code"] = rows["season"].map(
            lambda s: scoring.RULES_ERA_CODE[scoring.rules_era(s)])
        return rows

    def team_features(self, rows: pd.DataFrame) -> pd.DataFrame:
        """Add TEAM_FEATURES to team rows (TEAM_ROW_COLUMNS + asof). Same index and order."""
        _check_asof(rows)
        return self._add_team_features(rows.copy())
```

```python
def price_band(price):
    """0: up to £5.0m, 1: £5.5–7.0m, 2: £7.5–9.0m, 3: £9.5m+ (-1 if unknown)."""
    values = np.atleast_1d(np.asarray(price, dtype=float))
    bands = np.nan_to_num(pd.cut(values, PRICE_BINS, labels=False), nan=-1).astype(int)
    return bands if np.ndim(price) else int(bands[0])


def _prepare_players(h: pd.DataFrame) -> pd.DataFrame:
    """Add the helper columns RATE_STATS and the priors need."""
    h = h.copy()
    h["fixture"] = 1.0
    h["played"] = (h["minutes"] > 0).astype(float)
    h["played60"] = (h["minutes"] >= 60).astype(float)
    known = h["clearances_blocks_interceptions"].notna()
    h["cbit"] = (h["clearances_blocks_interceptions"] + h["tackles"]).fillna(0)
    h["cbirt"] = (h["clearances_blocks_interceptions"] + h["tackles"] + h["recoveries"]).fillna(0)
    h["minutes_dc"] = h["minutes"].where(known, 0)
    hit = scoring.defcon_hit(h)
    h["played_dc"] = h["played"] * hit.notna()   # outfield appearances with DefCon data
    h["defcon_hits"] = hit.fillna(0) * h["played_dc"]
    h["career_index"] = h.groupby("player_code").cumcount()
    h["debut_season"] = h.groupby("player_code")["season"].transform("first")
    h["price_band"] = price_band(h["price"].to_numpy())
    return h


def _player_state(h: pd.DataFrame) -> pd.DataFrame:
    """Running window sums after each of a player's matches, for as-of lookups."""
    player = h["player_code"]
    cols = {"player_code": player, "kickoff_time": h["kickoff_time"],
            "season": h["season"], "team": h["team"]}
    sum_cols = sorted({num for _, num, _, _ in RATE_STATS} | set(DENOMINATORS) | {"total_points"})
    for col in sum_cols:
        running = h[col].groupby(player).cumsum()
        for w in WINDOWS:
            cols[f"{col}__{w}"] = running - running.groupby(player).shift(w).fillna(0)
    for den in DENOMINATORS:
        cols[f"n_{den}"] = (h[den] > 0).astype(int).groupby(player).cumsum()
    cols["season_count"] = h.groupby(["player_code", "season"]).cumcount() + 1
    new_team = h["team"] != h.groupby("player_code")["team"].shift()
    run = new_team.astype(int).groupby(player).cumsum()
    cols["team_streak"] = h.groupby([player, run]).cumcount() + 1
    return pd.DataFrame(cols)


def _pooled(frame: pd.DataFrame, num: str, den: str, scale: float) -> float:
    total = frame[den].sum()
    return frame[num].sum() / total * scale if total >= MIN_PRIOR_DENOMINATOR[den] else np.nan


def _player_priors(h: pd.DataFrame, first_season: str) -> pd.DataFrame:
    """Default for each rate stat for a player with no history, by (position, price band).

    Learned from newcomers: each player's first NEWCOMER_MATCHES fixtures, for
    players who debut after the first season in the data (in the first season
    everyone looks new). Thin groups fall back to the position, then to all
    newcomers, then to everyone.
    """
    newcomers = h[(h["career_index"] < NEWCOMER_MATCHES) & (h["debut_season"] != first_season)]
    index = pd.MultiIndex.from_product([scoring.POSITIONS, range(len(PRICE_BINS) - 1)],
                                       names=["position", "price_band"])
    table = pd.DataFrame(index=index, columns=[name for name, *_ in RATE_STATS], dtype=float)
    for position, band in index:
        same_position = newcomers[newcomers["position"] == position]
        groups = [same_position[same_position["price_band"] == band], same_position, newcomers, h]
        for name, num, den, scale in RATE_STATS:
            values = (_pooled(g, num, den, scale) for g in groups)
            table.loc[(position, band), name] = next((v for v in values if not np.isnan(v)), np.nan)
    return table
```

```python
        feats["apps"] = m["s_n_played"].fillna(0)
        feats["matches_this_season"] = m["s_season_count"].where(m["s_season"] == m["season"], 0).fillna(0)
        feats["matches_for_current_team"] = m["s_team_streak"].where(m["s_team"] == m["team"], 0).fillna(0)
        feats["position_code"] = m["position"].map(POSITION_CODE)
        feats["pts_last5"] = (m[f"s_total_points__{BASELINE_WINDOW}"]
                              / m[f"s_fixture__{BASELINE_WINDOW}"]).fillna(0)

        out = rows.copy()
        for col, values in feats.items():
            out[col] = values.to_numpy()
        return self._add_team_features(out)
```

```python
"""The xP models.

Approach A (XPModel): one small LightGBM model per scoring part, combined with
FPL's rules. Approach B (TotalPointsModel): one LightGBM predicting total
points directly, used only as a yardstick in the backtest.
"""
import lightgbm as lgb
import numpy as np
import pandas as pd

from fpl import scoring
from fpl.features import PLAYER_FEATURES, TEAM_FEATURES, FeatureBuilder
from fpl.matches import with_asof

LGB_PARAMS = {"n_estimators": 200, "learning_rate": 0.05, "num_leaves": 31,
              "min_child_samples": 50, "subsample": 0.8, "subsample_freq": 1,
              "colsample_bytree": 0.8, "random_state": 0, "verbose": -1}
MIN_TRAIN_ROWS = 200            # fewer than this: predict the plain average
BONUS_WEIGHT_CURRENT_ERA = 3.0  # lean the bonus model towards the 2026/27 BPS rules


class _Constant:
    def __init__(self, value: float):
        self.value = float(value)

    def predict(self, X: pd.DataFrame) -> np.ndarray:
        return np.full(len(X), self.value)


class _Fitted:
    def __init__(self, model, binary: bool):
        self.model, self.binary = model, binary

    def predict(self, X: pd.DataFrame) -> np.ndarray:
        return self.model.predict_proba(X)[:, 1] if self.binary else self.model.predict(X)


def fit_part(objective: str, X: pd.DataFrame, y, weight=None):
    """Fit one part ('binary', 'poisson' or 'regression'). Too little data: use the average."""
    y = pd.Series(y).astype(float)
    if len(y) < MIN_TRAIN_ROWS or y.nunique() < 2:
        return _Constant(y.mean() if len(y) else 0.0)
    if objective == "binary":
        model = lgb.LGBMClassifier(**LGB_PARAMS)
        y = y.astype(int)
    else:
        model = lgb.LGBMRegressor(objective=objective, **LGB_PARAMS)
    model.fit(X, y, sample_weight=weight)
    return _Fitted(model, objective == "binary")


class XPModel:
    """Approach A: predict each scoring part, then apply FPL's rules."""

    def fit(self, players: pd.DataFrame, teams: pd.DataFrame) -> "XPModel":
        X = players[PLAYER_FEATURES]
        played = players["minutes"] > 0
        on = players[played]
        self.plays = fit_part("binary", X, played)
        self.sixty = fit_part("binary", X[played], on["minutes"] >= 60)   # P(60+ | plays)
        self.goals = fit_part("poisson", X[played], on["goals_scored"])
        self.assists = fit_part("poisson", X[played], on["assists"])
        keepers = played & (players["position"] == "GK")
        self.saves = fit_part("poisson", X[keepers], players.loc[keepers, "saves"])
        hit = scoring.defcon_hit(players)
        with_defcon = played & hit.notna()   # outfield players, DefCon seasons only
        self.defcon = fit_part("binary", X[with_defcon], hit[with_defcon])
        weight = np.where(on["rules_era"] == "2026_27", BONUS_WEIGHT_CURRENT_ERA, 1.0)
        self.bonus = fit_part("poisson", X[played], on["bonus"], weight)
        T = teams[TEAM_FEATURES]
        self.clean_sheet = fit_part("binary", T, teams["goals_against"] == 0)
        self.conceded = fit_part("poisson", T, teams["goals_against"])
        return self

    def predict(self, players: pd.DataFrame, teams: pd.DataFrame) -> pd.DataFrame:
        X = players[PLAYER_FEATURES]
        keep = ["season", "gw", "fixture_id", "player_code", "player_name", "position", "team",
                "opponent", "was_home", "price", "asof"]
        out = players[keep].reset_index(drop=True)
        is_gk = (out["position"] == "GK").to_numpy()
        out["p_plays"] = self.plays.predict(X)
        out["p_60"] = out["p_plays"] * self.sixty.predict(X)
        out["xg"] = self.goals.predict(X)
        out["xa"] = self.assists.predict(X)
        out["saves_lambda"] = np.where(is_gk, self.saves.predict(X), 0.0)
        out["p_defcon"] = np.where(is_gk, 0.0, self.defcon.predict(X))
        out["e_bonus"] = self.bonus.predict(X)
        # Cards: his own blended per-appearance rate, no model needed.
        out["p_yellow"] = players["yellow_rate_38"].fillna(0).clip(0, 1).to_numpy()
        out["p_red"] = players["red_rate_38"].fillna(0).clip(0, 1).to_numpy()
        T = teams[TEAM_FEATURES]
        team_pred = teams[["season", "fixture_id", "team"]].assign(
            p_cs=self.clean_sheet.predict(T), gc_lambda=self.conceded.predict(T))
        out = out.merge(team_pred, on=["season", "fixture_id", "team"], how="left")
        return scoring.expected_points(out)


class TotalPointsModel:
    """Approach B (yardstick): one LightGBM predicting total points directly."""

    def fit(self, players: pd.DataFrame) -> "TotalPointsModel":
        self.model = fit_part("regression", players[PLAYER_FEATURES], players["total_points"])
        return self

    def predict(self, players: pd.DataFrame) -> np.ndarray:
        return self.model.predict(players[PLAYER_FEATURES])


def train_and_predict(history: pd.DataFrame, player_rows: pd.DataFrame,
                      team_rows: pd.DataFrame, cutoffs: pd.DataFrame) -> pd.DataFrame:
    """Train A and B on `history`, then predict the given fixtures.

    history:     the match table: everything known at prediction time, nothing later
    player_rows: PLAYER_ROW_COLUMNS + asof for the fixtures to predict (no outcomes)
    team_rows:   TEAM_ROW_COLUMNS + asof for the same fixtures
    cutoffs:     matches.gw_cutoffs(), gives each training row its own asof
    Returns one row per player per fixture: parts, pts_*, xp (A), xp_b (B), baseline.
    """
    if len(history) and history["kickoff_time"].max() >= player_rows["asof"].min():
        raise ValueError("history has matches at or after the prediction time; "
                         "that would leak the future into training")
    builder = FeatureBuilder(history)
    train_players = builder.player_features(with_asof(builder.history, cutoffs))
    train_teams = builder.team_features(with_asof(builder.team_matches, cutoffs))
    model_a = XPModel().fit(train_players, train_teams)
    model_b = TotalPointsModel().fit(train_players)

    players = builder.player_features(player_rows)
    teams = builder.team_features(team_rows)
    pred = model_a.predict(players, teams)  # same row order as `players`
    pred["xp_b"] = model_b.predict(players)
    pred["baseline"] = players["pts_last5"].to_numpy()
    return pred


def apply_availability(pred: pd.DataFrame, players: pd.DataFrame, gw: int) -> pd.DataFrame:
    """Cap P(plays) at FPL's chance_of_playing_next_round for flagged players.

    Live predictions only (past news isn't stored), and only for gameweek `gw`.
    P(60+) is scaled down by the same factor so it stays below P(plays).
    """
    chance = players.set_index("code")["chance_of_playing_next_round"] / 100
    cap = pred["player_code"].map(chance).where(pred["gw"] == gw)
    capped = np.minimum(pred["p_plays"], cap.fillna(1.0))
    scale = (capped / pred["p_plays"]).where(pred["p_plays"] > 0, 1.0)
    out = pred.copy()
    out["p_plays"] = capped
    out["p_60"] = out["p_60"] * scale
    return scoring.expected_points(out)
```

```python
"""Walk-forward backtest.

For each gameweek: train only on matches before it, predict it (and the next
few weeks), then compare with what actually happened.
"""
import numpy as np
import pandas as pd

from fpl import scoring
from fpl.features import team_matches
from fpl.matches import PLAYER_ROW_COLUMNS, TEAM_ROW_COLUMNS, gw_cutoffs
from fpl.models import train_and_predict

TOP_N = 20
METHODS = {"A (parts)": "xp", "B (total points)": "xp_b", "Baseline (last 5)": "baseline"}


def _print(message: str) -> None:
    print(message, flush=True)


def walk_forward(history: pd.DataFrame, fixtures_all: pd.DataFrame, season: str, gws,
                 horizon: int = 1, log=_print) -> pd.DataFrame:
    """Predict each gameweek in `gws` (and up to horizon-1 weeks after) from earlier data only."""
    cutoffs = gw_cutoffs(fixtures_all)
    cutoff_of = {(s, g): c for s, g, c in cutoffs.itertuples(index=False)}
    in_season = history[history["season"] == season]
    played_gws = set(in_season["gw"])
    all_team_rows = team_matches(in_season)
    results = []
    for gw in gws:
        cutoff = cutoff_of[(season, gw)]
        past = history[history["kickoff_time"] < cutoff]
        if past["kickoff_time"].max() >= cutoff:
            raise AssertionError(f"training data for GW{gw} includes matches after its cutoff")
        targets = [g for g in range(gw, gw + horizon) if g in played_gws]
        actual = in_season[in_season["gw"].isin(targets)]
        player_rows = actual[PLAYER_ROW_COLUMNS].assign(asof=cutoff)
        # Later weeks' prices aren't known yet: use each player's price at this gameweek.
        known_price = actual[actual["gw"] == gw].groupby("player_code")["price"].first()
        player_rows["price"] = player_rows["player_code"].map(known_price).fillna(player_rows["price"])
        team_rows = all_team_rows[all_team_rows["gw"].isin(targets)][TEAM_ROW_COLUMNS].assign(asof=cutoff)

        pred = train_and_predict(past, player_rows, team_rows, cutoffs)

        outcomes = actual[["season", "fixture_id", "player_code", "total_points", "minutes",
                           "opp_goals"]].assign(defcon_hit=scoring.defcon_hit(actual).to_numpy())
        pred = pred.merge(outcomes, on=["season", "fixture_id", "player_code"], how="left")
        pred["origin_gw"] = gw
        pred["horizon"] = pred["gw"] - gw + 1
        results.append(pred)
        log(f"  {season} GW{gw}: trained on {len(past):,} rows, predicted {len(pred):,}")
    return pd.concat(results, ignore_index=True)


def per_player_gw(preds: pd.DataFrame) -> pd.DataFrame:
    """Add up fixtures so each player has one row per gameweek (double gameweeks summed)."""
    keys = ["season", "origin_gw", "horizon", "gw", "player_code", "position"]
    return preds.groupby(keys, as_index=False)[list(METHODS.values()) + ["total_points"]].sum()


def _weekly_mean(frame: pd.DataFrame, score) -> float:
    return float(np.mean([score(week) for _, week in frame.groupby("origin_gw")]))


def summarize(preds: pd.DataFrame) -> pd.DataFrame:
    """MAE, rank correlation and top-N actual points, per horizon and method."""
    by_player = per_player_gw(preds)
    rows = []
    for horizon, frame in by_player.groupby("horizon"):
        for method, col in METHODS.items():
            rows.append({
                "horizon": horizon, "method": method,
                "mae": (frame[col] - frame["total_points"]).abs().mean(),
                "spearman": _weekly_mean(frame, lambda w: w[col].rank().corr(w["total_points"].rank())),
                f"top{TOP_N}_points": _weekly_mean(frame, lambda w: w.nlargest(TOP_N, col)["total_points"].sum()),
                "player_gws": len(frame),
            })
    return pd.DataFrame(rows)


def calibration(preds: pd.DataFrame, buckets: int = 10) -> pd.DataFrame:
    """Predicted vs actual rates for the probability parts, one-week-ahead only."""
    h1 = preds[preds["horizon"] == 1]
    checks = {
        "p_plays": (h1, h1["minutes"] > 0),
        "p_60": (h1, h1["minutes"] >= 60),
    }
    teams = h1.drop_duplicates(["season", "fixture_id", "team"])
    checks["p_cs"] = (teams, teams["opp_goals"] == 0)
    defcon_rows = h1[(h1["minutes"] > 0) & h1["defcon_hit"].notna()]  # p_defcon is "if he plays"
    checks["p_defcon"] = (defcon_rows, defcon_rows["defcon_hit"] == 1)

    tables = []
    for part, (frame, outcome) in checks.items():
        if frame.empty:
            continue
        bucket = np.minimum((frame[part] * buckets).astype(int), buckets - 1)
        table = (pd.DataFrame({"bucket": bucket, "predicted": frame[part],
                               "actual": outcome.astype(float)})
                 .groupby("bucket", as_index=False)
                 .agg(predicted=("predicted", "mean"), actual=("actual", "mean"),
                      rows=("actual", "size")))
        tables.append(table.assign(part=part)[["part", "bucket", "predicted", "actual", "rows"]])
    return pd.concat(tables, ignore_index=True)
```

```python
"""Walk-forward backtest of the xP model against model B and a last-5 baseline.

Usage:
    python backtest.py                                    # 2025/26 GW1-38 + 2026/27 check (~10 min)
    python backtest.py --season 2025-26 --gws 1-5 --horizon 1   # quick run
"""
import argparse

import pandas as pd

from fpl import backtest, matches, storage
from fpl.seasons import CURRENT_SEASON


def parse_gws(text: str) -> list[int]:
    """'1-38' -> [1, ..., 38]; '7' -> [7]."""
    first, _, last = text.partition("-")
    return list(range(int(first), int(last or first) + 1))


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__,
                                     formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--season", help="one season to test, e.g. 2025-26")
    parser.add_argument("--gws", default="1-38", help="gameweeks with --season, e.g. 1-10")
    parser.add_argument("--horizon", type=int, default=6, help="weeks ahead to score (1-6)")
    args = parser.parse_args()

    history = matches.load_all_matches()
    fixtures_all = matches.load_all_fixtures()
    if args.season:
        runs = [(args.season, parse_gws(args.gws))]
    else:
        current = [g for g in matches.finished_gws(fixtures_all, CURRENT_SEASON) if g >= 2]
        runs = [("2025-26", list(range(1, 39))), (CURRENT_SEASON, current)]

    preds, summaries, calibrations = [], [], []
    for season, gws in runs:
        print(f"Backtesting {season}, GW{gws[0]}-{gws[-1]}...", flush=True)
        p = backtest.walk_forward(history, fixtures_all, season, gws, args.horizon)
        preds.append(p)
        summaries.append(backtest.summarize(p).assign(season=season))
        calibrations.append(backtest.calibration(p).assign(season=season))

    summary = pd.concat(summaries, ignore_index=True)
    storage.save_table("backtest_predictions", pd.concat(preds, ignore_index=True))
    storage.save_table("backtest_summary", summary)
    storage.save_table("backtest_calibration", pd.concat(calibrations, ignore_index=True))

    print()
    print(summary.to_string(index=False, float_format=lambda v: f"{v:.3f}"))
    first = summary[summary["horizon"] == 1].set_index(["season", "method"])
    for season in first.index.get_level_values("season").unique():
        a, base = first.loc[(season, "A (parts)")], first.loc[(season, "Baseline (last 5)")]
        print(f"\n{season}, next gameweek: A beats baseline on MAE: "
              f"{'yes' if a['mae'] < base['mae'] else 'NO'}; "
              f"on top-{backtest.TOP_N} points: "
              f"{'yes' if a[f'top{backtest.TOP_N}_points'] > base[f'top{backtest.TOP_N}_points'] else 'NO'}")


if __name__ == "__main__":
    main()
```

```python
"""Predict expected points (xP) for the next gameweek(s) and print a ranked table.

Usage:
    python predict.py               # next gameweek
    python predict.py --horizon 6   # next 6 gameweeks: one column per week plus a total
Run pull_data.py first so this season's data is fresh (and pull_history.py once).
"""
import argparse

import numpy as np
import pandas as pd

from fpl import matches, models, storage
from fpl.seasons import CURRENT_SEASON

NEXT_GW_COLUMNS = ["p_plays", "p_60", "xG", "xA", "p_cs", "p_defcon", "bonus", "xP", "baseline"]


def ranked_table(pred: pd.DataFrame, teams: pd.DataFrame, gws: list[int]) -> pd.DataFrame:
    """One row per player: next-gameweek breakdown, plus per-week xP if gws has several weeks."""
    short = {matches.canonical_team(n): s for n, s in zip(teams["name"], teams["short_name"])}
    who = pred.groupby("player_code").agg(player=("player_name", "first"), team=("team", "first"),
                                          pos=("position", "first"), price=("price", "first"))
    who["team"] = who["team"].map(short)
    nxt = pred[pred["gw"] == gws[0]].assign(
        fixture=lambda d: d["opponent"].map(short) + np.where(d["was_home"].astype(bool), " (H)", " (A)"),
        xG=lambda d: d["p_plays"] * d["xg"], xA=lambda d: d["p_plays"] * d["xa"],
        bonus=lambda d: d["p_plays"] * d["e_bonus"])
    stats = nxt.groupby("player_code").agg(
        next=("fixture", ", ".join), p_plays=("p_plays", "mean"), p_60=("p_60", "mean"),
        xG=("xG", "sum"), xA=("xA", "sum"), p_cs=("p_cs", "mean"), p_defcon=("p_defcon", "mean"),
        bonus=("bonus", "sum"), xP=("xp", "sum"), baseline=("baseline", "sum"))
    table = who.join(stats)
    table["next"] = table["next"].fillna("-")  # blank gameweek
    table[NEXT_GW_COLUMNS] = table[NEXT_GW_COLUMNS].fillna(0)
    sort_by = "xP"
    if len(gws) > 1:
        weekly = (pred.pivot_table(index="player_code", columns="gw", values="xp", aggfunc="sum")
                  .reindex(columns=gws).fillna(0))
        weekly.columns = [f"xP_gw{g}" for g in gws]
        table = table.join(weekly)
        table["xP_total"] = weekly.sum(axis=1)
        sort_by = "xP_total"
    return table.sort_values(sort_by, ascending=False).reset_index()


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__,
                                     formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--horizon", type=int, default=1, choices=range(1, 7),
                        help="how many gameweeks to predict (1-6)")
    parser.add_argument("--top", type=int, default=30, help="rows in the overall table")
    args = parser.parse_args()

    history = matches.load_all_matches()
    fixtures_all = matches.load_all_fixtures()
    players = storage.load_table("players")
    teams = storage.load_table("teams")
    gameweeks = storage.load_table("gameweeks")
    upcoming = gameweeks.loc[gameweeks["is_next"].astype(bool), "id"]
    if upcoming.empty:
        raise SystemExit("FPL lists no next gameweek (season over?). Re-run pull_data.py.")
    next_gw = int(upcoming.iloc[0])
    gws = [g for g in range(next_gw, next_gw + args.horizon) if g <= 38]

    cutoffs = matches.gw_cutoffs(fixtures_all)
    asof = cutoffs[(cutoffs["season"] == CURRENT_SEASON) & (cutoffs["gw"] == next_gw)]["cutoff"].iloc[0]
    player_rows = matches.upcoming_player_rows(fixtures_all, players, teams, CURRENT_SEASON, gws)
    team_rows = matches.upcoming_team_rows(fixtures_all, CURRENT_SEASON, gws)
    print(f"Training on {len(history):,} player-matches and predicting GW{gws[0]}"
          f"{f'-{gws[-1]}' if len(gws) > 1 else ''}...", flush=True)
    pred = models.train_and_predict(history, player_rows.assign(asof=asof),
                                    team_rows.assign(asof=asof), cutoffs)
    pred = models.apply_availability(pred, players, next_gw)

    table = ranked_table(pred, teams, gws)
    storage.save_table("xp_next", table)
    show = ["player", "team", "pos", "price", "next", *NEXT_GW_COLUMNS]
    if len(gws) > 1:
        show += [f"xP_gw{g}" for g in gws] + ["xP_total"]
    fmt = {"float_format": lambda v: f"{v:.2f}", "index": False}
    print(f"\nTop {args.top} players, GW{next_gw}:")
    print(table.head(args.top)[show].to_string(**fmt))
    for pos in ["GK", "DEF", "MID", "FWD"]:
        print(f"\nTop 10 {pos}:")
        print(table[table["pos"] == pos].head(10)[show].to_string(**fmt))
    print(f"\nAll players saved to {storage.DATA_DIR / 'processed' / 'xp_next.csv'}")


if __name__ == "__main__":
    main()
```
